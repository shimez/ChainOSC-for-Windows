# ChainOSC for Windows ユーザーガイド

[English version](../en/user-guide/)

ChainOSC for Windowsは、Windowsのグローバルホットキーを押した時／離した時に、指定したOSCメッセージを送信するアプリです。アプリをタスクトレイへ格納した状態でも動作します。

## 1. 動作環境

- Windows 10またはWindows 11（64bit）
- Microsoft Edge WebView2 Runtime
- OSCメッセージの送信先と通信できるネットワーク環境

WebView2 Runtimeは一般的なWindows 10／11環境には導入されています。アプリが起動しない場合は、Microsoftから最新のWebView2 Runtimeを導入してください。

## 2. 起動と終了

1. 配布されたZIPを任意のフォルダーへ展開します。
2. `chainosc-for-windows.exe`を起動します。
3. Windows DefenderやSmartScreenの確認が表示された場合は、配布元とファイルを確認してから実行してください。

ウィンドウの閉じるボタンを押した場合や最小化した場合、アプリは終了せずタスクトレイへ格納されます。格納中もグローバルホットキーとOSC送信は有効です。

- タスクトレイアイコンをダブルクリック：設定画面を表示
- トレイメニューの`Show ChainOSC`：設定画面を表示
- トレイメニューの`Exit`：アプリを完全に終了

アプリをもう一度起動した場合は、重複起動せず、すでに動作中の設定画面を表示します。

## 3. クイックスタート

1. OSC送信先の「ホスト名またはIPアドレス」と「UDPポート」を入力します。
2. Keyの「デバイス名」を入力します。
3. 「グローバルホットキー」の欄を選択し、使用したいキーの組み合わせを押します。
4. 「押した時」と「離した時」のOSCアドレス、型、値を設定します。
5. 「押した時をテスト」「離した時をテスト」で送信を確認します。
6. 「すべての設定を保存」を押します。

保存後は、設定したホットキーを別のアプリの操作中に押してもOSCメッセージが送信されます。

## 4. 共通設定

### 言語

UIを英語または日本語へ切り替えます。選択した言語は次回起動時にも使用されます。言語を切り替えても編集中の設定値は維持されます。

### システム

製品名、バージョン、実行環境を表示します。不具合を報告するときは、ここに表示されたバージョンを添えてください。

### OSC送信先

| 設定項目 | 説明 |
| --- | --- |
| ホスト名またはIPアドレス | OSCを受信するPCまたは機器のホスト名／IPアドレスです。同じPCへ送る場合は`127.0.0.1`を指定できます。 |
| UDPポート | OSC受信側のUDPポートです。VRChatの標準受信ポートは`9000`です。 |

### アプリケーション

「Windowsへのサインイン時に起動」を有効にすると、Windowsへサインインした際にChainOSCが自動起動します。自動起動時は設定画面を表示せず、タスクトレイに格納された状態で起動します。管理者権限は不要です。

> **重要：** ChainOSC for Windowsをアップデートまたは削除する場合は、事前に「Windowsへのサインイン時に起動」のチェックを外し、「すべての設定を保存」を実行してください。チェックを残したまま旧exeを削除または移動すると、Windowsの自動起動設定に旧exeのパスが残ります。

### 設定のバックアップと復元

ChainOSC for Windows全体の設定を、バージョン情報付きJSONとしてエクスポート／インポートします。次の内容が対象です。

- OSC送信先
- 自動起動設定
- すべてのKey
- デバイス名
- グローバルホットキー
- OSCメッセージおよびシーケンス設定

設定をインポートした後は、内容を確認して「すべての設定を保存」を押してください。

## 5. Keyの追加と基本設定

「＋ Keyを追加」を押すと、新しいKey設定が末尾に追加されます。Keyの数に固定上限はありませんが、同じグローバルホットキーを複数のKeyへ割り当てることはできません。

| 設定項目 | 説明 |
| --- | --- |
| デバイス名 | Keyを識別するための任意の名前です。 |
| グローバルホットキー | Windows上のどのアプリを操作中でも反応するキーまたはキーの組み合わせです。 |
| キーモード | 「押した時／離した時」または「シーケンス（押した時のみ）」を選択します。 |

グローバルホットキー欄を選択してから、使用したいキーの組み合わせを押してください。

- `Ctrl`、`Alt`、`Shift`、Windowsキーとの組み合わせに対応
- ファンクションキー、英数字、矢印、テンキー、Space、Tab、Enter、記号などに対応
- `Backspace`または`Delete`：割り当てを消去
- `Escape`：入力をキャンセル
- Windowsが予約している一部のショートカットは設定不可
- 重複するホットキーは設定時に警告

ホットキーを未設定のまま保存することもできます。その場合は保存時に警告が表示され、該当Keyはキーボード操作ではOSCを送信しません。テストボタンは使用できます。

## 6. 押した時／離した時モード

ホットキーを押した時と離した時に、それぞれ別のOSCメッセージを送信します。

「押した時」と「離した時」の合計で最大8件まで設定できます。各メッセージは表示されている順に送信されます。どちらか一方を0件にすると、その操作ではOSCを送信しません。

| 設定項目 | 説明 |
| --- | --- |
| OSCアドレス | `/`から始まるOSC Addressです。例：`/input/Jump` |
| 型 | `Int`、`Float`、`String`から選択します。 |
| 値 | OSCで送信する値です。選択した型として解釈できる値を入力します。 |

各メッセージでは次の操作ができます。

- `↑`／`↓`：送信順を変更
- 「削除」：メッセージを削除
- 「＋ OSCメッセージを追加」：現在表示している「押した時」または「離した時」へ追加

8件に達すると追加ボタンが無効になります。

## 7. シーケンス（押した時のみ）モード

ホットキーを押すたびに、開始値から増減量ずつ値を進めて送信します。終了値を超えると開始値へ戻ります。ホットキーを離した時には送信しません。

| 設定項目 | 説明 |
| --- | --- |
| OSCアドレス | 値を送信するOSC Addressです。 |
| 開始値 | 最初に送信する値です。 |
| 終了値 | シーケンスの終端です。 |
| 増減量 | 押すたびに加算する値です。負の値を指定すると減少します。`0`は指定できません。 |
| 型 | `Float`または`Int`など、送信する値の型です。`Int`では小数部分が切り捨てられます。 |

例として、開始値`0`、終了値`2`、増減量`1`の場合、押すたびに`0 → 1 → 2 → 0`の順で送信します。

## 8. テストと動作履歴

「押した時をテスト」「離した時をテスト」を使うと、グローバルホットキーを操作せず現在の入力内容でOSC送信を確認できます。

「動作履歴」には、送信したKey、操作、OSCアドレス、型、値、およびエラーが表示されます。受信側で反応しない場合の確認に利用してください。

## 9. Keyプリセット

各Key右上の「…」メニューから、Key単体の設定をJSONプリセットとしてエクスポート／インポートできます。

プリセットには次の内容が含まれます。

- キーモード
- 押した時／離した時のOSCメッセージ
- シーケンス設定

次のWindows固有情報は含まれません。

- デバイス名
- グローバルホットキー
- 内部ID

そのため、同じプリセットを別のKeyへ安全に適用できます。インポート後は設定内容を確認し、「すべての設定を保存」を押してください。

### 共有プリセットの入手先

M5ChainOSCで公開されているKeyプリセットをChainOSC for Windowsでも利用できます。

- [M5ChainOSC Key Presets](https://github.com/shimez/M5ChainOSC/tree/main/presets/key)

利用方法：

1. 上記ページから使用したいJSONファイルをダウンロードします。
2. 適用先Keyの右上にある「…」を開きます。
3. 「プリセットをインポート（JSON）」を選択します。
4. ダウンロードしたJSONファイルを選択します。
5. OSCアドレス、型、値を確認します。
6. 必要に応じてデバイス名とグローバルホットキーを設定します。
7. 「すべての設定を保存」を押します。

`ChainOSC-device-preset`形式に加え、旧`M5ChainOSC-device-preset`形式のKeyプリセットも読み込めます。Windows版からエクスポートしたプリセットは、M5ChainOSCおよびChainOSCminiでも利用できます。

## 10. Keyの削除

削除するKeyの右上にある「…」を開き、「Keyを削除」を選択します。削除後に「すべての設定を保存」を押すと、保存済み設定からも削除されます。

## 11. 未保存の変更と保存

設定を編集すると「未保存の変更」が表示されます。「すべての設定を保存」を押すと、設定の検証、グローバルホットキーの再登録、自動起動設定の更新が行われます。

アプリを終了する前や、設定のインポート後は必ず保存してください。重要な設定を変更する前には、全体設定をJSONでエクスポートしておくことを推奨します。

## 12. VRChatで使用する場合

VRChat側でOSCを有効にします。

1. VRChatのリングメニューを開きます。
2. 「Options」を開きます。
3. 「OSC」を開きます。
4. OSCを有効にします。

同じPC上のVRChatへ送信する場合、通常はホストに`127.0.0.1`、UDPポートに`9000`を指定します。OSCアドレスと値は、使用するVRChat機能やアバターのパラメーターに合わせて設定してください。

## 13. 利用上の注意

- グローバルホットキーは他のアプリによる同じキー操作をブロックしません。
- 別のアプリやWindowsが同じショートカットを使用している場合、意図しない操作が同時に発生する可能性があります。
- OSCはUDPを使用するため、配送保証や再送はありません。
- プリセットをインポートした場合は、OSC送信先や内容が用途に合っているか確認してください。
- ChainOSC for WindowsはVRChat、M5Stackおよび各関連企業の公式製品ではない個人開発の非公式プロジェクトです。

### アップデートする場合

1. 「Windowsへのサインイン時に起動」のチェックを外します。
2. 「すべての設定を保存」を押します。
3. タスクトレイの`Exit`からアプリを終了します。
4. 新しいZIPを展開し、既存の`chainosc-for-windows.exe`を上書きします。
5. 新版を起動して設定を確認します。
6. 自動起動を使用する場合は、チェックを入れ直して「すべての設定を保存」を押します。

### 削除する場合

1. 「Windowsへのサインイン時に起動」のチェックを外します。
2. 「すべての設定を保存」を押します。
3. タスクトレイの`Exit`からアプリを終了します。
4. ChainOSC for Windowsの配布フォルダーを削除します。

すでにexeを削除した後で自動起動設定が残っている場合は、PowerShellで次を実行すると削除できます。

```powershell
reg delete "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" /v "ChainOSCForWindows" /f
```
